# Contributing

Thank you for your interest in the ANR Muse EEG Recorder.

## Before contributing

- Keep the project focused on research EEG acquisition and reproducible data export.
- Do not add clinical diagnostic claims.
- Do not commit participant EEG recordings or personally identifying research data.
- Keep exported `.csv`, `.xlsx`, and local `data/` files out of Git.

## Development

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173` in Chrome or Microsoft Edge.

## Pull requests

Please describe:
- what changed;
- why the change is useful;
- how you tested Muse connectivity/recording if the change affects acquisition;
- any browser/OS limitations.

For research collaboration enquiries, contact ANR Lab at anrlab.ng@gmail.com.
